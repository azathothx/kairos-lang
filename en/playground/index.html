Kairos Playground

Evaluate Kairos expressions in the browser (the reference implementation runs as is — nothing is sent to any server). The language is at 1.0 (declared 2026-09-14) — see the language spec and the descriptor reference; the workbooks and sample questions are in Japanese.

Results appear here.

The evaluation range is the half-open interval [from, to) — from is included, to is excluded. In the output, # ⚠ marks annotations of out-of-range provenance and # coverage summary reports the data runway (spec §4.10). "Pin to URL" produces a shareable link carrying the expression and range. "Add to calendar (.ics)" turns the result into a file for your calendar app — one recurring event per expression (every occurrence listed as RDATE), timed points are zero-length events with an alarm, out-of-coverage intervals appear as events, and the leading comment line (# …) becomes the event name. Google and Apple Calendar on a PC import it as is (in Google Calendar the repeat field reads "does not repeat", yet deleting offers "all events", and re-importing a regenerated file updates the same event). On a phone choose "one event per point" (preselected on phones): the Google Calendar app ignores RDATE, keeps only the first occurrence as a single event, and after that Google refuses the recurring import of the same definition even from a PC (observed 2026-10-08). Outlook also needs "one event per point". The file is built in the browser (nothing is sent). Messages produced by the evaluator itself — syntax errors and annotation texts — appear in Japanese, the implementation's canonical output language; the English spec defines their exact semantics.
