決めたら、いつでも。
Write the rule once; list the dates.

暮らしの予定を穴埋めで決める → 月めくりで見る → 印刷するか、カレンダーアプリに入れる（.ics）。 式はページの裏で組み立て、Playground と同じ評価器がブラウザの中で計算する（サーバー送信なし・保存なし。 状態は URL に載る）。祝日は内閣府「国民の祝日について」の表（2026・2027 年分）＝Playground の例と同じ表。

Playground で開く

原文（評価器の註釈・被覆サマリ）

    

      
      
      
      
    

    
● 予定（時刻つきは時刻）・赤＝祝日・破線＝前後の月・← → キーで月めくり

  

  

  
この予定の式（Kairos）——Playground で開くとそのまま編集できる

  





評価範囲は [from, to) の右開区間。黄色の一言は、祝日の表の外（2028 年以降など）に
出た予定の知らせ——その期間の予定は祝日を知らずに並んでいる（原文は折りたたみ）。「カレンダーに入れる（.ics）」は Playground と同じ関数で
ファイルを作る——式ごとに 1 つの繰り返し予定・時刻つきの点は通知つき・PC の Google／Apple カレンダーはそのまま取り込める。
スマホのカレンダーアプリで開くときは「1 点ずつ別の予定にする」（スマホでは最初からオン）。Outlook 系も「1 点ずつ」。
「URL に固定」で例・穴の値・範囲・tz を URL に載せて共有できる（形は Playground と同じ #s=…&f=…&t=…&z=…＝
共有 URL の形）。祝日の自動更新・購読（webcal）はこのページでは行わない。
